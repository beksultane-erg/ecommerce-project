Искра - это веб-сайт интернет-магазина электроники, предназначенный для удобного просмотра, выбора и покупки электронных устройств и аксессуаров.

Основная цель проекта - создание современного и функционального интернет-магазина с удобным пользовательским интерфейсом.

Основные возможности:

1)Просмотр каталога товаров.

2)Поиск товаров по названию.

3)Фильтрация товаров по категориям.

4)Просмотр подробной информации о товарах.

5)Добавление товаров в корзину.

6)Добавление товаров в избранное.

7)Оформление заказов.

8)Регистрация и авторизация пользователей.

9)Адаптивный дизайн для различных устройств.

## Структура

```
.
├── index.html
├── assets/
│   └── images/
├── css/
│   ├── style.css
│   ├── base/
│   └── components/
└── js/
    ├── main.js
    └── modules/
```

## Как устроено

HTML — структура веб-страниц.
CSS — стилизация и адаптивная верстка.
JavaScript — интерактивность и функциональность.
Figma — разработка дизайна интерфейса.

### Ресурсы

Картинки лежат в `assets/images/`. Иконки интерфейса вставлены в разметку как inline SVG и берут цвет из `currentColor`.

## Добавить компонент

1. Разметка в `index.html`.
2. Файл `css/components/имя.css`.
3. Импорт в `css/style.css`.

Если нужен JS, создать `js/modules/имя.js` с функцией `initИмя()` и вызвать её в `js/main.js`.

## Запуск

Скрипты подключены с `type="module"`, поэтому через `file://` они не загрузятся. Нужен локальный сервер:

- расширение Live Server в VS Code, или
- `npx serve` / `python3 -m http.server` в папке проекта.
