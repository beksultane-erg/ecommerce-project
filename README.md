# ecommerce-project

Фронтенд интернет-магазина на HTML, CSS и JavaScript. Фреймворков и сборки нет, файлы отдаются браузеру как есть.

Пока сделаны шапка и боковое меню. Основной контент страницы ещё не сверстан.

## Структура

```
.
├── index.html
├── assets/
│   └── images/
├── css/
│   ├── style.css
│   ├── base/
│   └── components/
└── js/
    ├── main.js
    └── modules/
```

## Как устроено

### HTML

Вся разметка в `index.html`. Страница состоит из блоков: `header`, боковое меню `aside.drawer` с подложкой `overlay` и `main.page` под контент. У каждого блока свой корневой класс, по которому к нему цепляются стили и скрипты.

### CSS

Все стили подключаются через `css/style.css`. Порядок импортов важен:

1. `base/variables.css` с переменными: цвета, шрифт, скругления, размеры, z-index, длительность анимаций.
2. `base/reset.css` сбрасывает стили браузера.
3. `base/global.css` задаёт стили `body`, фокуса и служебные классы вроде `.no-scroll`.
4. `components/` содержит по файлу на каждый компонент.

Конкретные значения цветов и размеров пишутся только в `variables.css`, компоненты берут их через `var(--...)`. Так тему можно поменять в одном месте.

### JS

`js/main.js` импортирует модули из `js/modules/` и запускает их после `DOMContentLoaded`.

Каждый модуль экспортирует одну функцию `initИмя()`. Она находит свои элементы по `id`, а если их нет на странице, просто ничего не делает. Модули переключают классы (`.is-open`) и `aria-*` атрибуты, а как это выглядит, решает CSS.

Сейчас есть два модуля:

- `drawer.js` открывает и закрывает боковое меню (бургер, крестик, клик по фону, `Esc`), переносит фокус и блокирует прокрутку.
- `search.js` обрабатывает отправку формы поиска. Запрос к серверу пока не сделан, значение выводится в консоль.

### Ресурсы

Картинки лежат в `assets/images/`. Иконки интерфейса вставлены в разметку как inline SVG и берут цвет из `currentColor`.

## Правила

- Один компонент, один CSS-файл.
- Классы по БЭМ: `.block`, `.block__element`, состояния `.is-*`.
- Цвета и размеры только из переменных.
- Медиазапросы пишутся в файле компонента.
- JS не задаёт стили напрямую, только меняет классы и `aria-*`.

## Добавить компонент

1. Разметка в `index.html`.
2. Файл `css/components/имя.css`.
3. Импорт в `css/style.css`.

Если нужен JS, создать `js/modules/имя.js` с функцией `initИмя()` и вызвать её в `js/main.js`.

## Запуск

Скрипты подключены с `type="module"`, поэтому через `file://` они не загрузятся. Нужен локальный сервер:

- расширение Live Server в VS Code, или
- `npx serve` / `python3 -m http.server` в папке проекта.
