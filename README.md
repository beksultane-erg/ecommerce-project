# Шапка магазина

## Структура

```
project/
├── index.html                 разметка страницы
├── assets/
│   └── images/
│       └── logo.svg           логотип (версия для тёмного фона)
├── css/
│   ├── style.css              точка входа, подключает остальные файлы
│   ├── base/
│   │   ├── variables.css      цвета, шрифты, размеры
│   │   ├── reset.css          сброс стилей браузера
│   │   └── global.css         общие стили body, фокус
│   └── components/
│       ├── header.css         контейнер шапки
│       ├── burger.css         кнопка-бургер
│       ├── logo.css           логотип
│       ├── catalog-button.css кнопка «Каталог»
│       ├── search.css         поиск
│       ├── header-actions.css иконки справа
│       └── drawer.css         боковое меню
└── js/
    ├── main.js                точка входа, запускает модули
    └── modules/
        ├── drawer.js          логика бокового меню
        └── search.js          логика поиска
```

## Правила

- Один компонент = один CSS-файл. Имена классов по БЭМ: `.block__element`, состояние `.is-open`.
- Цвета и размеры берутся только из `variables.css` через `var(--...)`.
- Адаптив (`@media`) лежит внутри файла своего компонента.
- Новый JS-модуль: создать файл в `js/modules/`, экспортировать функцию `initЧто-то()` и вызвать её в `main.js`.

## Запуск

JS подключён как ES-модуль (`type="module"`), поэтому при открытии `index.html`
двойным кликом (`file://`) браузер скрипты не загрузит. Открывай через локальный сервер:

- VS Code → расширение **Live Server** → «Open with Live Server», или
- в папке проекта: `npx serve` или `python -m http.server`
