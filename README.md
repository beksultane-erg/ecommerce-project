# ecommerce-project

Фронтенд интернет-магазина на чистых HTML, CSS и JavaScript (ES-модули).
Без фреймворков, сборщиков и зависимостей: файлы в репозитории — это и есть то, что получает браузер.

Сейчас готовы шапка сайта (бургер, логотип, «Каталог», поиск, иконки действий) и боковое меню.
Контент страницы (`<main class="page">`) пока пустой.

## Архитектура

Проект разделён на три независимых слоя: разметка, стили и поведение.
Связывают их только имена классов (БЭМ) и `id` элементов.

```
index.html ──► css/style.css ──► base/variables.css   дизайн-токены
           │                 ├─► base/reset.css       сброс стилей браузера
           │                 ├─► base/global.css      общие стили
           │                 └─► components/*.css     по файлу на компонент
           │
           └─► js/main.js ──────► modules/*.js         по модулю на поведение
```

### Разметка — `index.html`

Одна страница, разбитая на смысловые блоки: `header`, `overlay` + `aside.drawer`, `main.page`.
Каждый блок — это компонент с корневым классом (`.header`, `.drawer`, `.search` …),
у которого есть свой CSS-файл и, если нужно, свой JS-модуль.
Доступность заложена в разметке: `aria-label`, `aria-expanded`, `aria-controls`, `aria-hidden`.

### Стили — `css/`

Стили подключаются через одну точку входа `css/style.css`, которая импортирует файлы в строгом порядке:

1. **`base/variables.css`** — дизайн-токены в `:root`: цвета, шрифт, скругления, размеры, z-index, длительности анимаций.
   Это единственное место, где задаются «сырые» значения.
2. **`base/reset.css`** — обнуление браузерных стилей.
3. **`base/global.css`** — стили `body`, фокуса и служебные классы (например, `.no-scroll`).
4. **`components/*.css`** — по одному файлу на компонент. Компонент описывает только себя
   и свои медиазапросы, а значения берёт из токенов через `var(--...)`.

Поэтому поменять тему (цвета, шрифт, размеры) можно в одном файле, а компоненты не зависят друг от друга.

### Поведение — `js/`

- **`js/main.js`** — точка входа. Импортирует модули и вызывает их `init*()` после `DOMContentLoaded`.
- **`js/modules/*.js`** — изолированные модули. Каждый экспортирует одну функцию `initЧтоТо()`, которая:
  - находит свои элементы по `id`;
  - тихо завершает работу, если их нет на странице (модуль безопасно подключать везде);
  - меняет состояние только через классы-состояния (`.is-open`) и `aria-*` атрибуты, а внешний вид задаёт CSS.

Текущие модули:

| Модуль | Что делает |
| --- | --- |
| `drawer.js` | Открывает и закрывает боковое меню по бургеру, крестику, клику по фону и `Esc`; переносит фокус, блокирует прокрутку страницы |
| `search.js` | Обрабатывает отправку формы поиска; запрос к серверу или переход на страницу результатов пока заглушка |

### Ресурсы — `assets/`

Статические файлы: изображения, иконки. Логотип — `assets/images/logo.svg`.
Иконки интерфейса встроены прямо в разметку как inline SVG и красятся через `currentColor`.

## Структура

```
.
├── index.html
├── assets/
│   └── images/
├── css/
│   ├── style.css           точка входа стилей
│   ├── base/               токены, сброс, глобальные стили
│   └── components/         стили компонентов
└── js/
    ├── main.js             точка входа скриптов
    └── modules/            модули поведения
```

## Соглашения

- **Один компонент — один CSS-файл.** Классы по БЭМ: `.block`, `.block__element`, состояние — `.is-*`.
- **Только токены.** Цвета, размеры, отступы слоёв и анимации — через `var(--...)` из `variables.css`.
- **Адаптив рядом с компонентом.** `@media` пишется в файле своего компонента, а не в отдельном файле.
- **JS не трогает стили напрямую.** Только классы-состояния и `aria-*`.

## Как добавить новое

**Компонент:**
1. Разметка с корневым классом в `index.html`.
2. Файл `css/components/<имя>.css`.
3. `@import` в `css/style.css` в секции «Компоненты».

**Поведение:**
1. Файл `js/modules/<имя>.js` с `export function init<Имя>() { ... }`.
2. Импорт и вызов в `js/main.js`.

**Новый токен:** добавить переменную в `css/base/variables.css` в нужную группу.

## Запуск

Скрипты подключены как ES-модули (`type="module"`), поэтому если открыть `index.html` двойным кликом (`file://`),
браузер их не загрузит. Запускайте через локальный сервер:

- VS Code → расширение **Live Server** → «Open with Live Server», или
- в папке проекта: `npx serve` или `python3 -m http.server`
